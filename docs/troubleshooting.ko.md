# ICOMON 저울 문제 해결

[English](troubleshooting.md) · [시작 페이지](../README.ko.md)

## 공통 문제 해결

[공통 Bluetooth 문제 해결](https://github.com/eigger/blesession/blob/main/docs/troubleshooting.ko.md)과 [프록시 설정](https://github.com/eigger/blesession/blob/main/docs/bluetooth.ko.md)을 먼저 확인하세요.

## 기기별 확인 사항

- 저울은 깨어 있을 때만 광고합니다. 광고에는 무게가 없으며 실제 무게는 GATT 연결을 통해 받습니다. 발견되었다고 연결 성공이 확인된 것은 아닙니다.
- 동시에 한 연결만 허용하므로 휴대폰 앱을 종료하세요. 다른 앱을 쓰려면 **자동 측정** 스위치를 끄세요. 별도의 계정·공통 인증 키는 이 통합에서 요구하지 않습니다.
- 프록시 GATT 연결은 `bluetooth_proxy.active: true`를 사용합니다. `esp32_ble_tracker.scan_parameters.active`는 스캔 응답 요청으로 다른 설정이며 이 통합의 광고 수신은 passive 모드입니다. 특별한 기기 근거 없이 interval/window를 바꾸지 마세요.
- 영점 및 전원 끄기 명령은 8바이트 주방 저울 펌웨어에서만 지원하며 커피 저울 펌웨어는 무시합니다.
- 검증 범위는 모의 BLE 전송을 사용하는 자동 테스트입니다. 개별 실물 모델·펌웨어·어댑터·프록시의 새 검증을 주장하지 않습니다.

## 증상과 조치

| 증상 | 실패 단계 | 확인 사항 | 조치 |
|---|---|---|---|
| 검색되지 않음 | 광고 | 전원·깨우기·MY_SCALE 이름과 서비스 | 저울을 켜고 HA의 Bluetooth 광고 수신을 확인합니다. |
| 검색되지만 연결 실패 | 연결 | 타 앱 점유·프록시 연결 슬롯·네트워크 | 휴대폰 앱을 종료하고 저울을 깨어 있게 한 채 재시도합니다. |
| 무게 갱신 없음 | 알림·측정 | 자동 측정 스위치·수신 데이터 | 스위치를 켜거나 **지금 측정**을 누르고 저울에 물건을 올립니다. |
| 영점·전원 끄기 실패 | 명령 | 깨어 있는 상태·펌웨어 변형 | 지원하는 주방 저울 펌웨어인지 확인합니다. 커피 펌웨어는 해당 명령을 무시합니다. |
| 예상치 못한 연결 끊김 | 링크 | 배터리·거리·프록시 전원과 네트워크 | 경로를 복구하고 깨운 뒤 재시도합니다. 정상 수면과 구분합니다. |

## 진단 및 로그

**최근 오류(Last error)**와 **오류 횟수(Error count)** 진단 센서에서 실패한 세션을 확인합니다. 정상 수면이나 사용자가 실행한 전원 끄기로 인한 연결 종료는 예상치 못한 링크 오류로 세지 않습니다. 연결 경로는 실제 확인된 경우에만 확정 정보로 해석하며, 광고를 받은 어댑터가 실제 연결을 담당했다고 단정하지 않습니다.

한 번의 재현 구간만 아래 로거로 수집한 뒤 디버그를 끄세요.

```yaml
logger:
  logs:
    custom_components.icscale: debug
```

## 문제가 계속되는 경우

기존 [Issues](https://github.com/eigger/hass-icscale/issues)에 위 로그와 최근 오류 센서 값을 첨부하세요. 확인 가능한 HA·통합·blesession 버전, 저울 모델·펌웨어, 어댑터 또는 프록시 모델·펌웨어, 로컬/프록시 경로, 실패 시각과 재현 절차를 포함합니다. 공개 전 MAC·내부 주소·개인정보를 제거하세요. 실제 기기에서의 성공과 실패, 자동 테스트 결과를 구분합니다.
